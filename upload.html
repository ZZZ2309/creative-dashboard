📊 创意数据上传

拖入 Excel（.xlsx）文件 → 自动更新仪表盘网站。无需登录、无需安装，浏览器即可操作。

① 连接设置 只需设置一次

令牌保存在你本机浏览器，不会上传到任何服务器。可在 GitHub → Settings → Developer settings → Personal access tokens 生成（勾选 repo 权限）。

② 选择 Excel 文件

📥 点击选择 或 把 Excel 拖到这里
支持 .xlsx / .xls ｜ 每行 = 一个创意在某一天的数据

③ 确认字段映射

系统已自动识别列，请核对是否正确（下拉开可手动调整）。带 * 为必填。
系统字段对应 Excel 列

④ 数据预览 0 行

上传成功后，网站约 1–2 分钟自动刷新。
